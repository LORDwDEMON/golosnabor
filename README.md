# ГолосНабор — локальная диктовка для Windows

Нажимаете и держите клавишу, говорите фразу, отпускаете — распознанный текст сам
вставляется в то окно, где стоит курсор (Word, браузер, любое поле ввода).
Распознавание идёт **на этом же компьютере** (движок whisper.cpp), интернет не нужен,
голос никуда не отправляется.

Репозиторий **приватный**: доступ только у владельца.

## Состояние

Проверено 08.11.2026 на рабочей машине: горячая клавиша, запись с микрофона,
распознавание короткой фразы за 1,6–1,8 с, вставка текста в активное окно,
история фраз, значок в области уведомлений, самопроверка на образце речи.

Приложение собрано как воссоздание **Type 2.0.0** по внешним признакам (разбор — в
`docs/ОТЧЁТ_РАЗБОРА.md`). Код и модель оригинала не копировались: распознавание идёт на
своём движке whisper.cpp, интерфейс написан заново.

## Как это работает

1. `app/main.js` — главный процесс: окна, значок в области уведомлений, глобальная
   горячая клавиша (по умолчанию **Scroll Lock**, режим «удерживать»).
2. `app/recorder.html` — скрытое окно записи микрофона (MediaRecorder), автоостановка
   по `maxSeconds`.
3. `app/lib/pipeline.cjs` — цепочка: webm → `ffmpeg` (wav 16 кГц моно) → локальный
   сервер распознавания (`app/lib/local-engine.cjs` запускает `whisper-server.exe`) → текст.
4. `app/lib/text.cjs` — обработка текста: лишние пробелы, пунктуация, заглавная буква.
5. `app/lib/input.ps1` — вставка в активное окно через SendInput, чтобы не ломать ввод
   в чужих приложениях.
6. `app/lib/store.cjs` — настройки и история в `%APPDATA%\golosnabor`.
7. Интерфейс: `app/panel.html` (панель управления 500×589), `app/overlay.html`
   (овал-индикатор записи, нарисован самостоятельно).

## Что в репозиторий НЕ входит и как это восстановить

Репозиторий содержит **код и документацию**. Три части сознательно не выложены —
каждая восстанавливается за несколько минут.

### 1. Среда запуска Electron — `app/node_modules` (~370 МБ)

Зависимость, а не файлы программы: ставится из `package-lock.json` одной командой.

```cmd
cd app
npm ci
```

Без Node.js в системе: поставить Node.js LTS, затем команду выше. После этого
`app\node_modules\electron\dist\electron.exe` появится сам.

### 2. Движок распознавания — `engine\bin` и модель `engine\models`

Сторонние файлы большого размера (341 МБ, из них 181 МБ — модель). Нужны для работы
приложения, но не являются кодом проекта. Состав и контрольные суммы — ниже.

Откуда брать:

- `whisper-cli.exe`, `whisper-server.exe`, `whisper.dll`, `ggml*.dll`,
  `libopenblas.dll` — официальная сборка **whisper.cpp** для Windows x64
  (<https://github.com/ggml-org/whisper.cpp>), вариант с BLAS.
- `ffmpeg.exe` — статическая сборка **FFmpeg** для Windows x64.
- `models\ggml-small-q5_1.bin` — модель Whisper `small`, квантование `q5_1`
  (каталог моделей whisper.cpp: <https://huggingface.co/ggerganov/whisper.cpp>).

Разложить по путям `engine\bin\` и `engine\models\` и сверить SHA-256 —
совпадение означает, что восстановлена ровно та сборка, на которой комплект проверялся.
Порядок восстановления и ускорение на видеокарте NVIDIA — в `ПРОЧТИ_МЕНЯ.md`.

Машиночитаемая опись движка лежит в репозитории — `engine\СОСТАВ_ДВИЖКА.json`
(19 файлов: роль, размер, SHA-256). Сверка одной командой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ПРОВЕРИТЬ_ДВИЖОК.ps1
```

Скрипт ничего не меняет: печатает таблицу «файл → состояние» и возвращает 0, если всё
совпало. Что внутри движка и как он вызывается — `docs\ДВИЖКИ_И_МОДУЛИ.md`.

### 3. Индикатор из оригинального приложения — `app\original-ui` (2,8 МБ)

Фрагмент сборки платного приложения **Type 2.0.0** (страница овала записи, шрифты,
стили). Он использовался по решению владельца для личной работы и **не выложен**:
это чужой проприетарный код, и владелец запретил передавать его третьим лицам —
в том числе размещать на чужих серверах. Кода и данных владельца в нём нет.

Приложение работает и без этой папки: `app/main.js` проверяет её наличие и, если её
нет, показывает свой овал `app/overlay.html` с тем же размером окна 168×119
(вид похожий, но нарисован самостоятельно).

## Быстрый старт

1. Развернуть папку целиком; `app` и `engine` должны лежать рядом — приложение ищет
   движок рядом с собой. Путь лучше без кириллицы.
2. Восстановить `app\node_modules` (см. выше) и `engine` (см. выше).
3. Двойной щелчок по `УСТАНОВИТЬ.cmd`: настройки `app\settings.default.json`
   копируются в `%APPDATA%\golosnabor\settings.json`, проходит самопроверка
   распознавания на `engine\образец-речи.wav`, создаётся ярлык «ГолосНабор».
4. Запуск — ярлык или `ЗАПУСТИТЬ.cmd`. Окно «Панель управления» плюс значок в области
   уведомлений; закрытие окна программу не выключает, выход — через меню значка.

При первом нажатии Windows может спросить разрешение на микрофон — разрешить.

## Управление

1. Поставить курсор туда, куда нужно печатать.
2. Нажать и **держать Scroll Lock**, говорить фразу, отпустить клавишу.
3. Через несколько секунд (3–12 с на офисном ПК) текст вставится сам.

В панели: хоткей (Scroll Lock, Caps Lock, Ctrl+Alt+Space, F9), способ диктовки,
тёмная тема, звуки, «Последняя фраза». Значок «набор» на панели — тоже кнопка
начала и конца диктовки.

Настройки и история: `%APPDATA%\golosnabor\settings.json` и `history.json`.

## Проверка

```cmd
cd app
node check.mjs
```

Ожидаемый ответ на образец речи — `Проверка голоса. Раз, два, три.`
Диагностика по журналу: запустить с переменной `GOLOSNABOR_DEBUG=1`, события
пишутся в `%TEMP%\golosnabor-debug.log`. Таблица неисправностей — в `ПРОЧТИ_МЕНЯ.md`.

## Работа с файлами программы из других инструментов

Репозиторий — обычный git-репозиторий, поэтому с файлами можно работать откуда угодно:

```cmd
git clone git@github.com:LORDwDEMON/golosnabor.git
```

- читать исходники и документацию напрямую (агенты, редакторы, скрипты);
- сравнивать свою копию с эталоном: `git status`, `git diff`;
- восстанавливать испорченный файл: `git checkout -- <файл>`;
- вести историю правок отдельными коммитами.

Клонирование даёт код и документацию; `npm ci` и движок добавляются один раз
(см. «Что в репозиторий НЕ входит»).

## Ограничения и права

- Windows 10/11, 64-бит; 4 ГБ ОЗУ; микрофон. Права администратора не нужны,
  в реестр и службы приложение ничего не пишет.
- Не переносилось из Type: расшифровка встреч с разделением говорящих, локальная
  языковая модель, векторная память, календарь, облачные модели, телеметрия.
- Чужой проприетарный код (Type) в репозитории отсутствует. Сторонние движки
  (whisper.cpp, FFmpeg) распространяются по своим лицензиям и в репозиторий
  не выложены — их файлы добавляются на месте.
- Секретов, ключей, паролей и личных данных в репозитории нет.

## Технические заметки

- **`ELECTRON_RUN_AS_NODE`.** Если запускать `electron.exe` из оболочки с этой
  переменной, окно не появится — Electron стартует как обычный Node. В `ЗАПУСТИТЬ.cmd`
  переменная снимается.
- **Кириллица в пути.** Движок не открывает модель по пути с русскими буквами;
  приложение обходит это копией модели в служебную папку, но папку лучше держать
  по латинскому пути.
- **Окна от администратора.** Windows не пускает синтетический ввод в приложения,
  запущенные от администратора: текст останется в буфере обмена.
- **`app/package.json`.** Команда `npm start` запускает Electron; в разделе `scripts`
  остался ключ `проверка` со ссылкой на несуществующий `проверка.mjs` — самопроверка
  живёт в `check.mjs` и вызывается из `УСТАНОВИТЬ.cmd` и вручную (см. «Проверка»).

# ГолосНабор — комплект для установки на другом компьютере

Локальная диктовка: нажали и держите Scroll Lock, сказали фразу, отпустили —
текст сам вставился в то окно, где вы работали. Распознавание идёт **на этом же
компьютере**, интернет не нужен, ничего никуда не отправляется.

Комплект полный: внутри уже лежит движок распознавания, модель, перекодировщик
звука и сам интерфейс. Ставить дополнительно ничего не нужно.

## Содержимое

```
папка комплекта\
├── УСТАНОВИТЬ.cmd        установка: настройки, ярлык, самопроверка
├── ЗАПУСТИТЬ.cmd         запуск (на него ведёт ярлык)
├── shortcut.ps1          создаёт ярлык на рабочем столе
├── app\                  приложение (~373 МБ)
│   ├── main.js           окна, значок, горячая клавиша, диктовка
│   ├── panel.html        панель управления 500×589
│   ├── settings.default.json  настройки, которые ставит установщик
│   ├── original-ui\      индикатор записи — страница из приложения Type
│   ├── lib\              движок речи, вставка текста, обработка текста
│   ├── check.mjs         самопроверка распознавания
│   └── node_modules\     Electron — среда запуска
├── engine\               движок распознавания (~341 МБ)
│   ├── bin\              whisper-server.exe, whisper-cli.exe, ffmpeg.exe, библиотеки
│   ├── models\           ggml-small-q5_1.bin (181 МБ) — модель распознавания
│   └── образец-речи.wav  запись для самопроверки
├── docs\                 памятка и отчёт о разборе
└── evidence\             снимки экрана и доказательства разбора
```

## Требования

- Windows 10 или 11, 64-бит.
- 1,5 ГБ свободного места, 4 ГБ оперативной памяти.
- Микрофон (встроенный или USB).
- Обычные права пользователя. Права администратора **не нужны**.
- Node.js нужен только для самопроверки при установке; для работы приложения — нет.

## Установка (три шага)

1. **Распаковать архив целиком** в любую папку, например `C:\GolosNabor`.
   Не разделяйте папки `app` и `engine` — приложение ищет движок рядом с собой.
   Путь может быть любым, но **лучше без кириллицы** (проверено: движок не открывает
   модель по пути с русскими буквами; приложение это обходит копией модели
   в служебную папку, но лишний риск ни к чему).
2. **Двойной щелчок по `УСТАНОВИТЬ.cmd`.** Что произойдёт:
   - настройки из комплекта (`app\settings.default.json`) скопируются
     в `%APPDATA%\golosnabor\settings.json` — если файла настроек ещё нет;
   - пройдёт самопроверка распознавания на записи `engine\образец-речи.wav`
     (ожидаемый ответ: `Проверка голоса. Раз, два, три.`);
   - появится ярлык «ГолосНабор» на рабочем столе.
3. **Запустить ярлык.** Появится окно «Панель управления» и значок в области уведомлений.

При первом нажатии клавиши Windows может спросить разрешение на микрофон — разрешить.

## Как пользоваться

1. Поставьте курсор туда, куда нужно печатать (Word, браузер, поле ввода).
2. Нажмите и **держите Scroll Lock**, говорите фразу, отпустите клавишу.
3. Через несколько секунд текст вставится сам.

Панель управления: хоткей (можно сменить на Caps Lock, Ctrl+Alt+Space или F9),
способ диктовки, тёмная тема, звуки, «Последняя фраза». Значок «набор» на панели —
тоже кнопка начала и конца диктовки.

Настройки и история: `%APPDATA%\golosnabor\settings.json` и `history.json`.

## Скорость

Модель компактная (small), считает на процессоре:

| Компьютер | Фраза 3 секунды |
| :--- | :--- |
| этот комплект, обычный офисный ПК | 5–12 секунд |
| новый процессор с AVX2 | 3–6 секунд |
| компьютер с видеокартой NVIDIA (см. ниже) | 1–3 секунды |

Это не мгновенно, зато не требует интернета и не отправляет голос наружу.

## Если на компьютере есть видеокарта NVIDIA — можно ускорить

1. Взять с машины, где комплект готовился, файлы из `D:\AETHER_V4\DSH-Voice\bin`:
   `ggml-cuda.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`, `cudart64_12.dll`,
   `nvrtc64_120_0.dll`, `nvrtc-builtins64_124.dll` — положить в `engine\bin`.
2. Большую модель `ggml-large-v3-turbo-q5_0.bin` (547 МБ) положить в `engine\models`.
3. В `app\lib\local-engine.cjs` убрать ключ `'--no-gpu'` из строки запуска сервера.
4. Запустить приложение заново.

Без этого шага всё работает, просто медленнее.

## Автозапуск при входе в Windows

```
schtasks /create /tn "GolosNabor" /tr "\"C:\GolosNabor\ЗАПУСТИТЬ.cmd\"" /sc onlogon /rl limited
```

Удалить: `schtasks /delete /tn "GolosNabor" /f`.

## Если не работает

| Что видно | Причина | Что делать |
| :--- | :--- | :--- |
| Окно не появляется | запускали `electron.exe` вручную из оболочки с переменной `ELECTRON_RUN_AS_NODE=1` | запускать через ярлык или `ЗАПУСТИТЬ.cmd` |
| «Ошибка загрузки плагина», белый экран | не хватает `node_modules` | распаковать архив целиком |
| «Речь не распознана» | тихо говорите или микрофон занят | проверить микрофон в настройках Windows |
| Текст не вставился, но есть в буфере | окно получателя запущено от администратора | Windows не пускает ввод в такие окна: запустить программу обычным способом |
| Распознавание 30–80 секунд | работает большая модель без видеокарты | оставить компактную модель или включить GPU (см. выше) |
| Самопроверка упала: «нет модели» | папка `engine` лежит отдельно | вернуть `engine` рядом с `app` |
| Scroll Lock не срабатывает | клавишу забрала другая программа | сменить хоткей в панели |
| Приложение стартует и сразу закрывается | антивирус заблокировал Electron | разрешить приложение в антивирусе |

Диагностика: запустить `ЗАПУСТИТЬ.cmd` после установки переменной
`set GOLOSNABOR_DEBUG=1` — события пишутся в `%TEMP%\golosnabor-debug.log`.

## Что умеет и чего не умеет

Умеет: диктовка с вставкой в активное окно, локальное распознавание, история,
панель управления, индикатор записи как у Type, горячая клавиша, тёмная тема.

Не умеет (это есть в оригинальном Type, но не переносилось): расшифровка встреч
с разделением говорящих, локальная языковая модель, векторная память, календарь,
облачные модели, телеметрия.

## Важно про права

В папке `app\original-ui` лежит часть сборки приложения **Type 2.0.0** — индикатор
записи. Она используется по решению владельца для личной работы. Передавать комплект
третьим лицам вместе с этой папкой нельзя. Если это мешает, удалите `app\original-ui` —
приложение переключится на свою страницу `app\overlay.html` (вид похожий, но нарисован
самостоятельно).

## Откат

Удалить папку комплекта, `%APPDATA%\golosnabor` и задачу `GolosNabor` (если создавали).
В систему приложение ничего не прописывает: служб и записей в реестр нет.

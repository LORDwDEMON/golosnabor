# ГолосНабор — воссоздание приложения Type по внешним признакам

Что это: рабочая локальная диктовка для Windows, собранная по результатам разбора
приложения **Type 2.0.0** из `F:\PROGRAM1`. Код и модель исходного приложения
не копировались — распознавание идёт на движке whisper.cpp этой машины.

Проверено 08.11.2026: горячая клавиша, запись с микрофона, распознавание
(1,6–1,8 с на короткой фразе), вставка текста в активное окно, история, значок
в области уведомлений.

## Кратко о разборе

- `Type.exe` в `F:\PROGRAM1` — установщик NSIS (32-бит), 894 МБ.
- Папка «Type распакованные файлы» — распакованная копия установленного приложения;
  рабочая установка на этой машине — `C:\Program Files\Type`, версия 2.0.0,
  Electron 41.2.0.
- Внутри: 261 исходный файл, 291 канал IPC, 4 окна (главное, панель управления,
  предпросмотр расшифровки, уведомление о встрече), сборка Vite.
- Основной режим — локальный: GigaAM v3 (ONNX, 844 МБ) для речи, sherpa-onnx для
  разделения говорящих и определения речи, llama.cpp для языковой модели,
  эмбеддинги all-MiniLM-L6-v2 и Qdrant для памяти. Облачные модели — дополнение.

## Что воссоздано и что нет

Полностью воссоздан основной сценарий: хоткей → запись → локальное распознавание →
вставка в активное окно, плюс панель управления, плавающий указатель, история
и настройки. Не переносились: расшифровка встреч с разделением говорящих,
локальная языковая модель и векторная память, интеграция с календарём,
облачные модели, телеметрия (её в воссоздании нет вовсе).

Подробнее — `docs\ПАМЯТКА.md`, раздел «Чем это отличается от оригинала».

## Как перенести на другой компьютер

Комплект самостоятельный: движок речи, модель и перекодировщик лежат внутри `engine\`,
интернет не нужен. Порядок: распаковать папку целиком → запустить `УСТАНОВИТЬ.cmd` →
работать через ярлык на рабочем столе.

- Подробно для человека — `ПРОЧТИ_МЕНЯ.md` (установка, настройка, ускорение на
  видеокарте NVIDIA, таблица неисправностей, автозапуск).
- Пошагово для ИИ-агента — `ИНСТРУКЦИЯ_ДЛЯ_ИИ_АГЕНТА.md` (проверки с ожидаемым
  выводом, диагностика по журналу, матрица неисправностей, шаблон отчёта).
- Готовый архив комплекта — `F:\ГОТОВЫЕ_АРХИВЫ\ГолосНабор_комплект_2026-11-08.zip`
  рядом с файлом `КОНТРОЛЬНАЯ_СУММА.txt` (SHA-256).

## Как запустить

Двойной щелчок по `ЗАПУСТИТЬ.cmd`. Горячая клавиша по умолчанию — **Scroll Lock**,
режим «удерживать»: держите клавишу, пока говорите, отпустите — текст вставится.
Закрытие окна не выключает программу: она живёт в области уведомлений, выход — через
меню значка.

Если запускать приложение из скриптов DSH, сначала снимите переменную
`ELECTRON_RUN_AS_NODE` (в `ЗАПУСТИТЬ.cmd` это уже сделано), иначе Electron стартует
как обычный Node и окно не появится.

# Инструкция для ИИ-агента: развёртывание и проверка «ГолосНабора»

Документ адресован другому ИИ-агенту (LLM с доступом к файлам и командной строке
Windows). Человеку, который просто хочет пользоваться программой, нужен
`ПРОЧТИ_МЕНЯ.md`. Здесь — пошаговое развёртывание, проверки с ожидаемым результатом,
диагностика и правила безопасности.

## 1. Что за система

«ГолосНабор» — портативное приложение для Windows, локальная диктовка:
человек держит клавишу **Scroll Lock**, говорит, отпускает; приложение записывает
звук, распознаёт его на этом же компьютере и вставляет текст в активное окно.

Устройство:

| Слой | Файлы | Что делает |
| :--- | :--- | :--- |
| Оболочка | `app\main.js` | окна, значок в области уведомлений, горячая клавиша, запуск движка |
| Интерфейс | `app\panel.html`, `app\panel.js` | панель управления 500×589 |
| Индикатор | `app\original-ui\` | страница записи, взятая из приложения Type (отдаётся локальным сервером) |
| Запись звука | `app\recorder.html` | микрофон через `getUserMedia`, автоостановка по тишине |
| Конвейер | `app\lib\pipeline.cjs` | ffmpeg → распознавание → обработка текста |
| Обработка текста | `app\lib\text.cjs` | пробелы, знаки, заглавные, завершающая точка |
| Движок речи | `engine\bin\whisper-server.exe` | сервер распознавания (порт выбирается свободный) |
| Модель | `engine\models\*.bin` | компактная модель `ggml-small-q5_1.bin` |
| Вставка текста | `app\lib\input.ps1` | печать Unicode-событиями через `SendInput` |
| Настройки | `%APPDATA%\golosnabor\settings.json` | хоткей, режим, язык, способ вставки |
| История | `%APPDATA%\golosnabor\history.json` | распознанные фразы |

Ключевые особенности, которые нельзя «оптимизировать»:

1. Приложение запускается **только** через `ЗАПУСТИТЬ.cmd` или ярлык: в нём снимается
   переменная `ELECTRON_RUN_AS_NODE`, иначе Electron работает как Node и молча выходит.
2. Движок распознавания **не открывает файлы по путям с кириллицей**: приложение само
   копирует модель в `%LOCALAPPDATA%\GolosNabor\models` с латинским путём и берёт оттуда.
3. Движок в комплекте — процессорный: сервер запускается с ключом `--no-gpu`.
4. Индикатор записи — страница из Type; она грузится по `http://127.0.0.1:<порт>/`,
   потому что ES-модули по `file://` не загружаются.
5. Вставка текста идёт печатью Unicode-событиями, а не `Ctrl+V`. В окна, запущенные
   от администратора, ввод не проходит в принципе (ограничение Windows).

## 2. Предварительная проверка компьютера

Выполнить в PowerShell:

```powershell
[Environment]::OSVersion.VersionString        # ожидается 10.0.19041 и выше
$env:PROCESSOR_ARCHITECTURE                    # ожидается AMD64
[math]::Round((Get-PSDrive C).Free/1GB,1)      # ожидается не меньше 2 ГБ
Test-Path "$env:APPDATA\golosnabor"            # True — система уже ставилась ранее
```

Микрофон: `Get-PnpDevice -Class AudioEndpoint | Where-Object Status -eq 'OK'`
— должен быть хотя бы один вход.

Если места меньше 2 ГБ или система 32-битная, установка невозможна — сообщить человеку.

## 3. Развёртывание (по шагам)

### Шаг 1. Распаковать целиком

Распаковать архив в папку без кириллицы в пути, например `C:\GolosNabor`.
Проверить полноту:

```powershell
$k = 'C:\GolosNabor'
Test-Path "$k\app\node_modules\electron\dist\electron.exe"   # True
Test-Path "$k\engine\bin\whisper-server.exe"                 # True
Test-Path "$k\engine\models\ggml-small-q5_1.bin"             # True
"{0:N0} МБ" -f ((Get-ChildItem $k -Recurse -File | Measure-Object Length -Sum).Sum/1MB)
```

Ожидаемый объём комплекта — около **800 МБ**. Если меньше, архив распакован не полностью.

### Шаг 2. Запустить установщик

```powershell
& cmd.exe /c "`"C:\GolosNabor\УСТАНОВИТЬ.cmd`" < nul"
```

Ожидаемый вывод (текст латиницей, потому что так надёжнее для cmd):

```
[1/4] Prilozhenie na meste.
[2/4] Dvizhok raspoznavaniya na meste.
[3/4] Nastrojki sozdany.            (или "uzhe est" / "skopirovany iz komplekta")
[4/4] Proverka raspoznavaniya, do minuty...
  движок из комплекта: да
  модель: C:\Users\<имя>\AppData\Local\GolosNabor\models\ggml-small-q5_1.bin
  текст: "Проверка голоса. Раз, два, три."
  РЕЗУЛЬТАТ: ГОДНО
ярлык: C:\Users\<имя>\Desktop\ГолосНабор.lnk
```

Критерий успеха: строка `РЕЗУЛЬТАТ: ГОДНО` и созданный ярлык.
Если Node.js на компьютере нет, шаг 4 пропускается — это допустимо, но тогда
самопроверку сделать вручную (шаг 5).

### Шаг 3. Запустить приложение

```powershell
Start-Process "$env:USERPROFILE\Desktop\ГолосНабор.lnk"
Start-Sleep -Seconds 12
Get-Process | Where-Object { $_.Path -like '*GolosNabor*electron.exe' } |
  Select-Object Id, MainWindowTitle
```

Ожидается: 7–9 процессов Electron, у одного заголовок окна **«ГолосНабор»**.
Панель управления показывает: хоткей `Scroll Lock`, способ «Удерживать хоткей».

### Шаг 4. Убедиться, что поднялся движок

```powershell
$env:GOLOSNABOR_DEBUG = '1'   # затем перезапустить приложение, чтобы журнал писался
Get-Content "$env:TEMP\golosnabor-debug.log" -Tail 20
```

Ожидаемые строки в журнале:

```
страница оригинала: http://127.0.0.1:<порт>/index.html
свой сервер распознавания: http://127.0.0.1:<порт>     (если внешнего сервера нет)
```

Если есть рабочая внешняя служба распознавания на `127.0.0.1:8001`, приложение
возьмёт её и напишет `используем внешний сервер распознавания`.

### Шаг 5. Проверить диктовку без микрофона (стенд)

```powershell
$env:GOLOSNABOR_TEST_WAV = 'C:\GolosNabor\engine\образец-речи.wav'   # перед запуском приложения
```

Затем открыть Блокнот, поставить в него курсор, нажать и отпустить Scroll Lock.
Ожидается: в Блокноте появляется `Проверка голоса. Раз, два, три.`, а в
`%APPDATA%\golosnabor\history.json` — новая запись с полями `text`, `engine`, `ms`, `inserted`.

Если текста нет, а история пополнилась — проблема во вставке (см. таблицу).
Если история не пополнилась — проблема в распознавании.

### Шаг 6. Проверить живой микрофон

Открыть Блокнот, зажать Scroll Lock, произнести фразу, отпустить.
Ожидается: индикатор-овал по центру верха экрана во время речи, затем текст в Блокноте.

## 4. Чек-лист приёмки

- [ ] `node app\check.mjs` → `РЕЗУЛЬТАТ: ГОДНО`
- [ ] Окно «ГолосНабор» открывается, панель показывает `Scroll Lock`
- [ ] В журнале есть строка про движок распознавания
- [ ] Scroll Lock запускает индикатор (овал появляется)
- [ ] Текст вставляется в Блокнот (стенд и живая речь)
- [ ] `history.json` пополняется, поле `inserted` = `type` или `paste`
- [ ] Ярлык на рабочем столе запускает приложение
- [ ] После выхода через меню значка процессов Electron не остаётся

## 5. Настройка

Файл `%APPDATA%\golosnabor\settings.json` (создаётся установщиком):

| Поле | Значение по умолчанию | Смысл |
| :--- | :--- | :--- |
| `hotkey` | `ScrollLock` | клавиша диктовки: `ScrollLock`, `Capslock`, `Control+Alt+Space`, `F9` |
| `dictationMode` | `hold` | `hold` — держать клавишу; `toggle` — нажал/нажал |
| `language` | `ru` | язык распознавания |
| `autoPaste` | `true` | вставлять в активное окно |
| `insertMode` | `type` | `type` — печать Unicode; `paste` — через буфер обмена |
| `punctuation` | `auto` | `auto` — достраивать запятые правилами; `off` — только чистка |
| `questionMark` | `off` | `auto` — догадываться о вопросе по первому слову; `off` — не догадываться |
| `sounds` | `true` | звуковые сигналы начала и конца |
| `darkTheme` | `false` | тёмная панель |
| `maxSeconds` | `60` | предел длительности записи |

После правки файла приложение нужно перезапустить. Хоткей и тему можно менять
и в самой панели (щелчок по строке).

Добавить модель: положить файл `*.bin` в `engine\models`. Приоритет выбора —
`ggml-small-q5_1.bin`, затем `ggml-large-v3-turbo-q5_0.bin`, затем любой первый `*.bin`.

Ускорить на компьютере с NVIDIA: положить в `engine\bin` файлы `ggml-cuda.dll`,
`cublas64_12.dll`, `cublasLt64_12.dll`, `cudart64_12.dll`, `nvrtc64_120_0.dll`,
`nvrtc-builtins64_124.dll`; убрать `'--no-gpu'` из `app\lib\local-engine.cjs`.

## 6. Диагностика

Журнал: `%TEMP%\golosnabor-debug.log` (включается переменной `GOLOSNABOR_DEBUG=1`
до запуска приложения). Что там искать:

| Строка | Смысл |
| :--- | :--- |
| `страница оригинала: http://...` | индикатор поднялся из `app\original-ui` |
| `свой сервер распознавания: http://...` | движок из комплекта запущен |
| `модель скопирована в служебную папку` | первый запуск, разовая подготовка модели |
| `processRecording: <файл>` | запись принята в обработку |
| `ошибка распознавания: ...` | движок вернул ошибку |
| `[указатель] процесс отрисовки упал` | сбой видеодрайвера, окно перезагружается само |

Проверка движка вручную (без приложения):

```powershell
& C:\GolosNabor\engine\bin\whisper-server.exe -m "$env:LOCALAPPDATA\GolosNabor\models\ggml-small-q5_1.bin" --host 127.0.0.1 --port 8123 --no-gpu -t 4
# в другом окне:
Invoke-WebRequest http://127.0.0.1:8123/ -UseBasicParsing     # ожидается 200
```

## 7. Матрица неисправностей

| Симптом | Причина | Проверка | Лечение |
| :--- | :--- | :--- | :--- |
| Окно не появляется | запуск не через `ЗАПУСТИТЬ.cmd`; унаследована `ELECTRON_RUN_AS_NODE` | `$env:ELECTRON_RUN_AS_NODE` не пусто | запускать ярлыком; в скрипте переменная снимается |
| Приложение выходит с кодом 0 за секунду | то же самое | журнал Electron не создаётся | то же |
| «Нет модели» / движок молчит | модель не скопировалась | есть ли `%LOCALAPPDATA%\GolosNabor\models\*.bin` | удалить папку копии, перезапустить |
| Движок падает сразу (код `-1073741515`) | не хватает библиотек рядом с exe | есть ли `ggml.dll`, `ggml-cpu-*.dll`, `whisper.dll` в `engine\bin` | вернуть файлы из архива |
| Движок падает (код `-1073740791`) | путь к модели с кириллицей | путь в команде запуска | работать через приложение (оно копирует модель) |
| Распознавание 30–80 с | большая модель на процессоре | имя модели в журнале | оставить `ggml-small-q5_1.bin` |
| Распознавание зависает | сервер запущен без `--no-gpu`, видеокарты нет | аргументы процесса `whisper-server.exe` | вернуть `--no-gpu` |
| Текст не вставляется, в истории есть | окно получателя с правами администратора; либо `insertMode` сломан | `inserted` в истории | запустить программу обычным способом; проверить `insertMode` |
| Вместо текста одна буква `v` | старый способ вставки (`SendKeys`) | версия `app\lib\input.ps1` | использовать комплектный `input.ps1` (SendInput) |
| Индикатор пустой, прозрачный | страница оригинала не загрузилась | строка `страница оригинала` в журнале | удалить `app\original-ui` — включится своя страница |
| «Ошибка загрузки плагина», белый экран | повреждён профиль/`node_modules` | размер `app\node_modules` | распаковать архив заново |
| Scroll Lock не реагирует | клавишу заняла другая программа | нажать хоткей в панели (`Caps Lock`) | сменить клавишу |

## 8. Правила для агента

1. **Не удалять** `%APPDATA%\golosnabor\history.json` — это история человека.
2. **Не менять** `app\original-ui` — это код чужого приложения (Type 2.0.0);
   пересобирать или «чинить» его не нужно, при проблемах достаточно отключить папку.
3. **Не запускать** `electron.exe` напрямую из оболочки с `ELECTRON_RUN_AS_NODE` —
   приложение выйдет молча и это будет выглядеть как поломка.
4. **Не убивать** процессы `electron.exe`, принадлежащие другим приложениям
   (DeepSeek Harness, Claude, VS Code) — фильтровать по пути `*GolosNabor*`.
5. Перед правкой `settings.json` — сделать копию `settings.json.bak-<дата>`.
6. Откат любой правки: вернуть копию файла; откат установки: удалить папку комплекта,
   `%APPDATA%\golosnabor` и задачу `GolosNabor`.
7. Проверку вставки делать в Блокноте или другом обычном окне, не в окнах с правами
   администратора и не в защищённых полях ввода пароля.

## 10. Что в комплект не входит

Расшифровка встреч с разделением говорящих, локальная языковая модель, векторная
память, календарь, облачные модели и телеметрия — всё это есть в оригинальном Type,
но в воссоздание не переносилось. Не пытайтесь «включить» эти функции: их кода здесь нет.

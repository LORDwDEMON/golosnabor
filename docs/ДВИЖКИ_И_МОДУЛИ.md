# Движки и модули: что работает внутри и что не выложено

Технические сведения о том, на чём стоит ГолосНабор: движок распознавания речи, модель,
перекодировщик звука, среда запуска и её зависимости. Всё, что ниже, — либо снято с самих
файлов комплекта (версии, размеры, SHA-256, параметры модели), либо взято из отчёта разбора
оригинального приложения; источники указаны по ходу текста.

Дата снятия сведений: **17.11.2026**. Машина: Windows, процессор без AVX-512 (грузится
бэкенд Sandy Bridge), 4 потока распознавания.

Связанные файлы:

- `engine/СОСТАВ_ДВИЖКА.json` — машиночитаемая опись движка (19 файлов, размер и SHA-256);
- `ПРОВЕРИТЬ_ДВИЖОК.ps1` — сверка описи с файлами на диске;
- `README.md` — раздел «Что в репозиторий НЕ входит и как это восстановить».

## 1. Что не выложено и почему

| Часть | Состав | Объём | Причина |
| :--- | :--- | ---: | :--- |
| `engine\bin` | 17 файлов: движок whisper.cpp, бэкенды ggml, BLAS, FFmpeg | 160,1 МБ | сторонние сборки; `ffmpeg.exe` (100,5 МБ) больше предела GitHub в 100 МБ на файл |
| `engine\models` | `ggml-small-q5_1.bin` | 181,3 МБ | модель больше предела GitHub в 100 МБ на файл |
| `app\node_modules` | 565 файлов, Electron и его зависимости | 369,8 МБ | среда запуска, а не код программы; ставится `npm ci` (внутри `electron.exe` — 238,3 МБ, тоже сверх предела) |
| `app\original-ui` | фрагмент сборки Type 2.0.0 | 2,8 МБ | чужой проприетарный код; по решению владельца не публикуется |

Каждая часть восстанавливается своим штатным способом (разделы 2–5), а `SHA-256`
из `engine/СОСТАВ_ДВИЖКА.json` позволяет убедиться, что восстановлена ровно та сборка,
на которой комплект проверялся.

## 2. Движок распознавания речи: whisper.cpp 1.9.4

Whisper — модель распознавания речи OpenAI (encoder-decoder Transformer), whisper.cpp —
её перенос на C/C++ поверх ggml без Python и без интернета.

### 2.1 Версия

```
load_backend: loaded BLAS backend from ...\engine\bin\ggml-blas.dll
load_backend: loaded CPU backend from ...\engine\bin\ggml-cpu-sandybridge.dll
whisper.cpp version: 1.9.4
```

(вывод `whisper-cli.exe --version`, 17.11.2026)

### 2.2 Файлы движка и их роль

| Файл | Размер | Роль |
| :--- | ---: | :--- |
| `whisper-server.exe` | 712 КБ | HTTP-сервер распознавания, основной путь в приложении |
| `whisper-cli.exe` | 468 КБ | консольный распознаватель, запасной путь |
| `whisper.dll` | 1,3 МБ | библиотека whisper.cpp (загрузка модели, инференс) |
| `ggml.dll` | 61 КБ | вычислительное ядро ggml (графы вычислений) |
| `ggml-base.dll` | 674 КБ | базовая часть ggml: структуры, регистрация бэкендов |
| `ggml-blas.dll` | 54 КБ | бэкенд BLAS — матричные умножения через OpenBLAS |
| `libopenblas.dll` | 48,8 МБ | собственно OpenBLAS |
| `ggml-cpu-*.dll` (9 файлов) | 0,8–0,9 МБ каждый | варианты CPU-бэкенда под наборы инструкций: `x64`, `sse42`, `sandybridge`, `haswell`, `alderlake`, `cannonlake`, `cascadelake`, `icelake`, `skylakex` |
| `ffmpeg.exe` | 100,5 МБ | перекодирование записи в wav 16 кГц моно |

Девять вариантов CPU-бэкенда — это не «на всякий случай»: движок выбирает один из них
при запуске по фактическим возможностям процессора, поэтому одна и та же сборка работает
и на старом офисе без AVX2, и на новом процессоре с AVX-512.

### 2.3 Как приложение запускает движок

Основной путь (`app/lib/local-engine.cjs`): на свободном порту петли поднимается сервер,
модель загружается один раз и остаётся в памяти — поэтому короткая фраза распознаётся
за 1,6–1,8 с, а не за десяток секунд.

```
whisper-server.exe -m <модель> --host 127.0.0.1 --port <свободный порт> --no-gpu -t 4
```

- `--no-gpu` обязателен: в комплекте только процессорные библиотеки, без него сборка
  пытается работать с видеокартой и запросы зависают.
- `-t 4` — четыре потока; больше на офисном процессоре выигрыша не даёт.
- приложение ждёт готовности сервера до 40 с и гасит его при выходе.

Запрос (`app/lib/pipeline.cjs`):

```
POST http://127.0.0.1:<порт>/inference
multipart/form-data:
  file            = audio.wav (wav 16 кГц моно)
  response_format = json
  language        = ru
  temperature     = 0
→ { "text": "..." }
```

Запасной путь, если сервер не поднялся:

```
whisper-cli.exe -m <модель> -f <wav> -l ru -nt -otxt -of <префикс>
```

Результат читается из `<префикс>.txt`, файл затем удаляется. Оба пути возвращают текст
в `app/lib/pipeline.cjs`, дальше его приводит в порядок `app/lib/text.cjs`.

### 2.4 Замер на образце речи

Холодный запуск `whisper-cli.exe` на `engine\образец-речи.wav` (3 секунды речи), 4 потока:

| Показатель | Значение |
| :--- | ---: |
| загрузка модели и распознавание, всего | 12,87 с |
| вычисление мел-спектрограммы | 11,65 мс |
| декодирование, на прогон | 61,76 мс (2 прогона) |
| обработка батчей, на прогон | 55,83 мс (63 прогона) |
| ответ | `Проверка голоса. Раз, два, три.` |

В приложении модели уже в памяти, поэтому на короткую фразу уходит 1,6–1,8 с
(проверка комплекта 08.11.2026).

### 2.5 Ускорение на видеокарте NVIDIA

Процессорные бэкенды — единственные, что лежат в комплекте. Для CUDA нужно добавить в
`engine\bin` файлы `ggml-cuda.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`,
`cudart64_12.dll`, `nvrtc64_120_0.dll`, `nvrtc-builtins64_124.dll`, положить в
`engine\models` модель `ggml-large-v3-turbo-q5_0.bin` (547 МБ) и убрать `--no-gpu`
из строки запуска сервера в `app/lib/local-engine.cjs`. Ожидаемый эффект — 1–3 с на фразу
вместо 3–12 с.

## 3. Модель распознавания

`engine\models\ggml-small-q5_1.bin`, 190 085 487 байт, SHA-256
`ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb`.

Параметры печатает сам движок при загрузке (вывод `whisper_model_load`, 17.11.2026):

| Параметр | Значение | Что означает |
| :--- | ---: | :--- |
| `type` | 3 | архитектура **small** (около 244 млн параметров) |
| `n_vocab` | 51 865 | словарь многоязычной модели |
| `n_langs` | 99 | число языков, включая русский |
| `n_audio_ctx` | 1500 | кадров аудиоконтекста (30 с звука) |
| `n_audio_state` | 768 | размерность представлений кодера |
| `n_audio_head` | 12 | голов внимания в кодере |
| `n_audio_layer` | 12 | слоёв кодера |
| `n_text_ctx` | 448 | токенов текстового контекста |
| `n_text_state` | 768 | размерность представлений декодера |
| `n_text_head` | 12 | голов внимания в декодере |
| `n_text_layer` | 12 | слоёв декодера |
| `n_mels` | 80 | мел-полос в спектрограмме |
| `ftype` | 9 | тип квантования весов в файле (файл помечен `q5_1`) |
| `qntvr` | 1 | версия формата квантования |
| `adding 1608 extra tokens` | — | служебные токены поверх словаря |
| размер в памяти | 189,49 МБ | то, что занимает загруженная модель |

Почему именно `small` и именно `q5_1`: `small` — разумный компромисс точности и скорости
на процессоре без видеокарты, квантование `q5_1` уменьшает файл с ~900 МБ (fp32) до 181 МБ
почти без потери качества на бытовой речи. Модель многоязычная: распознаёт русский и
заодно умеет переводить на английский (это свойство самого Whisper, в приложении
не используется).

Сверка подлинности: размер и SHA-256 из описи `engine/СОСТАВ_ДВИЖКА.json`, проверка
скриптом `ПРОВЕРИТЬ_ДВИЖОК.ps1`.

## 4. FFmpeg 9.0.2 — перекодирование звука

Запись из браузерного `MediaRecorder` приходит в WebM/Opus, движок ждёт wav 16 кГц моно,
поэтому между ними стоит FFmpeg.

```
ffmpeg version 9.0.2-essentials_build-www.gyan.dev
built with gcc 16.2.0 (Rev3, Built by MSYS2 project)
configuration: --enable-gpl --enable-version3 --enable-static ...
libavutil 61.1.102 · libavcodec 63.1.102 · libavformat 63.1.102
libavfilter 12.1.102 · libswscale 10.1.102 · libswresample 7.1.102
```

(вывод `ffmpeg.exe -version`, 17.11.2026)

Как применяется (`app/lib/pipeline.cjs`):

```
ffmpeg.exe -hide_banner -loglevel error -y -i <запись.webm> -ar 16000 -ac 1 -c:a pcm_s16le <временный .wav>
```

- результат пишется в `%TEMP%`, а не рядом с записью, чтобы в папке комплекта не оставались хвосты;
- запись короче 2 КБ считается слишком короткой и не отправляется на распознавание;
- тайм-аут перекодирования — 120 с, распознавания — 180 с (сервер) и 300 с (CLI).

Это отдельный `ffmpeg.exe`, а не `ffmpeg.dll` из состава Electron: у Electron-версии урезан
набор кодеков и нет процесса-утилиты. Сборка `essentials_build` распространяется по GPLv3 —
поэтому её файл лежит на месте, но в репозиторий не выложен.

## 5. Среда запуска: Electron 45.2.3

главный процесс (окна, горячая клавиша, движок, вставка текста).

Установленная версия (`app/node_modules/electron/package.json`, `dist/version`): **45.2.3**.
В `app/package.json` требование `^45.2.3`, в `app/package-lock.json` (lockfileVersion 3)
зафиксированы точные версии всего дерева:

## 6. Порядок восстановления и проверка

1. `cd app && npm ci` — среда запуска.
2. Положить в `engine\bin` сборку whisper.cpp 1.9.4 для Windows x64 с BLAS и статическую
   сборку FFmpeg 9.0.2; в `engine\models` — модель `ggml-small-q5_1.bin`.
3. Сверить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ПРОВЕРИТЬ_ДВИЖОК.ps1
```

Скрипт печатает таблицу «файл → состояние» и итог. Успех выглядит так:

```
итог: совпало 19, нет файла 0, другой размер 0, другой SHA-256 0
Движок на месте: распознавание работать будет.
```

Код возврата 0 — всё на месте; 1 — есть недостающие или испорченные файлы (какие именно,
видно в таблице). Проверено 17.11.2026 под PowerShell 5.1 и PowerShell 7.

4. Самопроверка распознавания: `УСТАНОВИТЬ.cmd` или `cd app && node check.mjs` —
   ожидаемый ответ на образец: `Проверка голоса. Раз, два, три.`

## 7. Лицензии сторонних частей

| Часть | Лицензия | Что это значит для репозитория |
| :--- | :--- | :--- |
| whisper.cpp и ggml | MIT | можно распространять, но бинарники крупные — лежат на месте |
| Модель Whisper (веса) | MIT (OpenAI) | то же |
| FFmpeg `essentials_build` | GPLv3 | требует распространения условий GPL при передаче бинарника; поэтому бинарник не выложен |
| Electron | MIT | ставится из npm, в репозитории только версия в `package-lock.json` |
| Пакеты Node.js из дерева | MIT / ISC | то же |

Код самого ГолосНабора объявлен в `app/package.json` как MIT; интерфейс и логика написаны
заново по внешним признакам оригинала (см. `docs/СТРУКТУРА_ПРОГРАММЫ.md`, часть II).

## 8. Подводные камни

| Симптом | Причина | Что делать |
| :--- | :--- | :--- |
| распознавание висит, тайм-аут | запущен сервер без `--no-gpu`, а CUDA-библиотек нет | ключ `--no-gpu` в `app/lib/local-engine.cjs` |
| «нет модели» / движок не открывает файл | папка `engine` лежит отдельно от `app` или путь содержит кириллицу | положить `engine` рядом с `app`; приложение обходит кириллицу копией модели в ASCII-путь |
| долгие 30–80 с на фразу | подсунута большая модель (`large-v3` без видеокарты) | вернуть `ggml-small-q5_1.bin` |
| `whisper-cli` пишет `unknown model` | файл модели повреждён или недокачан | сверить SHA-256 по описи |
| «Ошибка загрузки плагина», белый экран | не хватает `app\node_modules` | `npm ci` в папке `app` |
| движок загрузился, но текст пустой | запись короче 2 КБ отброшена как слишком короткая | держать клавишу дольше |

# Структура программы: своя и оригинальная

Документ из двух частей: как устроен **ГолосНабор** (то, что лежит в этом репозитории) и как
была устроена **оригинальная программа Type 2.0.0**, по внешним признакам которой он собран, —
с расположением файлов, моделей и подсистем.

Сведения сняты 17.11.2026 с файлов на диске и из отчёта разбора
`docs/ОТЧЁТ_РАЗБОРА.md` (выгрузка доказательств — `evidence/доказательства.json`).
Где вывод сделан по косвенным признакам, это сказано прямо.

## 2. Путь одной диктовки

```
Scroll Lock (удержание)
   │
   ├─ main.js: опрос клавиши через powershell + GetAsyncKeyState, шаг 40 мс
   │            (режим «переключатель» — globalShortcut)
   ▼
recorder.html → MediaRecorder (WebM/Opus) → IPC recorder:done
   │
   ▼
main.js → lib/pipeline.cjs → ffmpeg (wav 16 кГц моно)
   │
   ├─ lib/local-engine.cjs: whisper-server на 127.0.0.1:<порт> → POST /inference
   └─ запасной путь: whisper-cli.exe -nt -otxt
   ▼
lib/text.cjs: чистка, регистр, знаки препинания
   │
   ▼
lib/input.ps1: SendInput в активное окно (режим type) или буфер обмена (режим paste)
   │
   ▼
lib/store.cjs: запись в history.json
```

## 3. Окна и значки

| Окно | Размер | Когда есть | Назначение |
| :--- | :--- | :--- | :--- |
| Панель управления | 500×589 | постоянно (закрытие прячет в значок) | настройки, история, кнопка диктовки |
| Овал записи | 168×119 | во время записи и распознавания | индикатор: запись → размышление → вставка |
| Запись микрофона | скрытое | постоянно, пока идёт диктовка | `MediaRecorder`, автоостановка по `maxSeconds` |
| Значок в области уведомлений | — | постоянно | меню: показать панель, выйти; текущий хоткей |

## 4. Каналы между процессами

Вызовы из окна в главный процесс (5): `panel:get-state`, `panel:set-setting`,
`panel:toggle`, `panel:show-history`, `panel:open-folder`.

События из главного процесса в окна (10): `panel:state`, `panel:history`,
`overlay:state`, `overlay:level`, `recorder:start`, `recorder:stop`, `recorder:done`,
`recorder:level`, `recorder:too-long`, `orig:send`.

## 5. Локальные серверы и порты

| Сервер | Адрес | Что отдаёт |
| :--- | :--- | :--- |
| `whisper-server.exe` | `http://127.0.0.1:<свободный порт>` | `POST /inference` — распознавание wav |
| `orig-ui-server.cjs` | `http://127.0.0.1:<свободный порт>` | статика папки `original-ui`; слушает только петлю, выход за папку запрещён (403) |

Порты выбираются системой при старте, наружу ничего не открывается.

## 6. Где лежат данные

`app.getPath('userData')` → `%APPDATA%\golosnabor\`:

- `settings.json` — настройки (хоткей, режим, язык, тема, звуки, `maxSeconds`, знаки препинания);
- `history.json` — история фраз, не больше 500 записей, свежие сверху.

Значения по умолчанию — в `app\lib\store.cjs` и `app\settings.default.json`
(установщик копирует второй в `settings.json`, если файла ещё нет).

## 7. Если правишь код: ловушки

- **`ELECTRON_RUN_AS_NODE`.** При запуске из оболочки с этой переменной Electron стартует
  как обычный Node и окно не появляется. `ЗАПУСТИТЬ.cmd` переменную снимает.
- **Пути по умолчанию в `store.cjs`** указывают на машину разработки
  (`D:\AETHER_V4\DSH-Voice\...`) и на внешний сервер `http://127.0.0.1:8001`. При старте
  `main.js` перекрывает их локальным движком из комплекта; переменная `GOLOSNABOR_SERVER_URL`
  позволяет задать сервер распознавания вручную.
- **Кириллица в пути.** Движок не открывает модель по пути с русскими буквами: `main.js`
  копирует модель в ASCII-путь (`asciiModelPath`). Папку лучше держать по латинскому пути.
- **Вставка текста.** Два режима: `type` — SendInput посимвольно, `paste` — буфер обмена.
  В окна, запущенные от администратора, Windows ввод не пускает: текст останется в буфере.
- **`app/package.json`.** Команда `проверка` в `scripts` ссылается на несуществующий
  `проверка.mjs`; самопроверка — `check.mjs`.
- **Стенды `app\_test\`** запускают подпроцессы и создают окна: на рабочем компьютере
  их лучше не гонять без нужды.

## 7. Что живёт на диске у оригинала

- **База** — SQLite (`better-sqlite3` 12.8.0, модуль `database.js`): заметки, расшифровки,
  календарные записи, токены Google.
- **Секреты** — `secretCrypto.js`: шифрование ключей, отдельный файл секретов и резервная
  копия мастер-ключа (`_getSecretFilePath`, `_saveSecretKey`, `_backupPath`); на macOS
  дополнительно связка ключей (`_initKeychain`).
- **Модели** — `resources\gigaam-model\`, `resources\bin\speech-vad\`; остальные
  скачиваются в каталог моделей при первом использовании.
- **Кеш обновлений** — каталог `open-whispr-updater`.
- **Настройки** — каталог `.openwhispr` (имя видно в строках кода).

Точные пути вычисляются при запуске, поэтому здесь указаны каталоги и модули, а не готовые
строки путей.

## 8. Что воспроизведено у нас и где это лежит

| Что делает оригинал | У нас |
| :--- | :--- |
| глобальная клавиша, режим «удерживать» и «переключатель» | `app/main.js`: опрос `GetAsyncKeyState` через PowerShell (40 мс) и `globalShortcut` |
| запись микрофона с автоостановкой | `app/recorder.html`, `maxSeconds` в настройках |
| локальное распознавание речи | `app/lib/local-engine.cjs` + `whisper-server.exe` (whisper.cpp, модель `small`) |
| перекодирование звука | `app/lib/pipeline.cjs` + `ffmpeg.exe` (16 кГц моно) |
| вставка текста в активное окно | `app/lib/input.ps1` (SendInput) и режим буфера обмена |
| чистка и оформление текста | `app/lib/text.cjs` (пробелы, регистр, знаки по правилам) |
| панель управления и история | `app/panel.html`, `app/panel.js`, `app/lib/store.cjs` |
| индикатор записи | `app/overlay.html` (свой) либо `app/original-ui` (страница из сборки Type, в репозиторий не входит) |
| значок в области уведомлений | `app/main.js` (`Tray`, меню) |

Не переносилось: расшифровка встреч с разделением говорящих, локальная языковая модель,
векторная память, календарь, облачные модели, телеметрия.

## 9. Что и почему не копировалось

- **Код оригинала.** `app.asar` не распаковывался в репозиторий: это чужой проприетарный
  код. Воссоздание сделано по внешним признакам, код и модель оригинала не копировались.
- **Страница овала записи** (`app\original-ui`, 2,8 МБ из сборки Type) — по решению

- **Движок и модель whisper.cpp** (341 МБ) — не выложены из-за размера; порядок
